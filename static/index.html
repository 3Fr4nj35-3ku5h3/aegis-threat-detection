Decision support for network security triage

Aegis scores network-flow style records with a hybrid pipeline: unsupervised anomaly detection plus supervised attack-family classification. Output is built for analysts — risk, confidence, rationale, and recommended next steps. It does not auto-block traffic.

  • Isolation Forest — deviation from benign baseline
  • Random Forest — benign / probe / dos / r2l / u2r
  • Fused risk — operational priority for the queue
